# Export and import data

## Export your data to CSV
Open the project, choose the Export button in the top-right toolbar, and pick CSV. Large exports are
prepared in the background and emailed to you as a download link that works for 7 days.

## Import data from a CSV file
Open the project, choose Import, and upload a CSV with a header row. You can map each column to a
field before the import starts. Rows with errors are skipped and listed in a report.

## Export limits
Exports include up to 1,000,000 rows. For larger data sets, filter the view first or use the API.
