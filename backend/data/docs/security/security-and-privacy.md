# Security and privacy

## Turn on two-factor authentication (2FA)
Go to Settings, then Security, then Two-factor authentication. Scan the QR code with an
authenticator app and enter the code to confirm. Save the backup codes somewhere safe.

## Report a security issue or a hacked account
> Handled by a person.

Suspected account takeovers, vulnerabilities and data exposure are handled by our security team.
The agent hands these tickets to a person immediately and does not ask for passwords or codes.

## Request a copy of your personal data
> Handled by a person.

Data access and privacy requests are legal requests and are handled by a person on our team.
